# interview-shadow

이력서와 채용공고를 근거로 **면접 준비 자료를 만들고, 그 자료로 모의면접을
반복하는** Claude Code 스킬입니다.

CS 퀴즈를 내지 않습니다. 경력자 면접에서 기술 지식은 개념을 물어서 드러나지 않고
**본인이 내린 결정의 전제**로 드러나기 때문입니다. 그래서 이력서에 쓴 문장 하나를
붙잡고 다섯 층까지 내려갑니다.

## 설치

```bash
git clone https://github.com/midagedev/interview-shadow.git
cp -r interview-shadow/skills/interview <프로젝트>/.claude/skills/
```

또는 개인 스킬로 어디서든 쓰려면:

```bash
cp -r interview-shadow/skills/interview ~/.claude/skills/
```

## 쓰는 법

준비 디렉토리에 이력서·경력기술서를 넣고 시작합니다. 형식은 `.md`·`.pdf`·`.docx`
무엇이든 됩니다.

```
~/interview-prep/
├── 이력서.pdf
└── 경력기술서.md
```

```
/interview
```

첫 실행에서는 자료가 없으니 **부트스트랩**을 먼저 합니다 — 문서를 찾아 읽고,
채용공고를 받아 팀을 조사하고, 진입점 목록을 만듭니다. 그다음부터는 바로
면접이 시작됩니다.

세션마다 `interview/` 아래에 리포트와 INDEX가 쌓이고, **다음 세션은 INDEX를 읽고
지난번 막힌 층 바로 위에서 이어갑니다.** 같은 첫 질문을 반복하지 않습니다.

### 모드

```
/interview            # 앞둔 전형 단계에 맞춰 자동 선택
/interview screen     # 1차·화상 인터뷰 — 넓고 얕게, 문답 8~12회
/interview deep       # 직무·심층 인터뷰 — 한 항목을 5층까지
/interview mixed      # 형식을 모르는 상황 자체를 훈련
/interview full       # 실전 통짜 재현 + 역질문 + 총평
/interview audit      # 질문하지 않고 이력서의 취약 지점만 보고
/interview 캐시 설계   # 지정 항목만 깊게
```

## 설계에서 중요한 것 세 가지

### 제출본과 준비용 판본을 구분합니다

**면접관이 읽은 것은 실제로 제출한 문서뿐입니다.** 준비하면서 더 자세히 써 둔
판본이 있어도 면접관은 모릅니다. 그래서 진입점을 두 갈래로 나눕니다.

- **제출본에 있는 문장** → 면접관이 실제로 묻습니다. 질문은 여기서만 출발합니다.
- **제출본에 없는 내용** → 면접관이 묻지 않습니다. 지원자가 **먼저 꺼내야만**
  나옵니다. 연습 목표가 "답하기"가 아니라 **"답변에 끼워 넣기"** 입니다.

이 구분을 안 하면, 실전에 오지 않는 질문에 대비하면서 정작 가진 카드는 못 쓰고
끝납니다.

### 세션이 누적됩니다

항목마다 상태를 매깁니다 — `미시도` / `L<n> 막힘` / `통과` / `굳음`.
3층에서 막혔으면 다음 세션은 1층부터 다시 묻지 않고 **2층에서 시작해 곧장 3층으로**
내려갑니다. 실제 2차 면접이 1차 답변을 딛고 들어오는 것과 같은 구조입니다.

같은 층에서 세 번 막히면 드릴을 반복하지 말고 이론 문서나 원본 자료로 돌아가라고
기록에 남습니다.

### 답변 길이를 글자 수로 판정합니다

"너무 길다"는 판정 불가능한 기준이라 발화하지 않습니다. 그래서 **한국어 약 350자
(말하면 60초)** 를 넘으면 그 자리에서 끊고 **다시 답하게** 합니다. 총평에만 적으면
교정이 되지 않기 때문입니다. 세션당 2회까지만 끊습니다 — 그 이상은 잔소리입니다.

## 무엇을 하지 않는가

- **면접관 개인을 특정하거나 추측하지 않습니다.** 조사 대상은 팀이 공개적으로
  밝힌 관점이지 개인이 아닙니다.
- **답을 먼저 알려주지 않습니다.** 자료에서 정답을 알고 있어도 질문만 합니다.
- **기록에 회사 내부 정보를 옮기지 않습니다.** 내부 식별자, 사내 문서 제목, 보안
  상세, 고객 데이터, 재무 수치는 빼고 남깁니다. 면접에서 실제로 할 발화도 어차피
  그 선을 넘으면 안 되므로, 이 제약은 연습의 일부입니다.
