# 2단계 — 기록: 다음 세션이 읽을 것

기록의 목적은 하나다. **다음 세션이 같은 질문을 반복하지 않고 막힌 지점 위에서
이어가게 하는 것.** 속기록이 아니다.

---

## 1. 구두 총평

세션 끝에 말로 정리한다.

1. **잘 선 것** — 구체성·인과·대안 인식이 드러난 답변. 어느 답변이 좋았는지 인용.
2. **무너진 지점** — **어느 층에서 막혔는지 층 번호와 함께.**
3. **다음에 준비할 것** — 항목별로 한 줄.
4. **평가 축별 판정** — `laddering.md`의 7축(구체성/인과/대안 인식/경계 인식/
   정직성/기여 경계/전이)으로. 각 축에 근거를 한 줄씩.
5. **못 쓴 카드** — 진입점 B(제출본에 없는 강한 카드)를 안 꺼냈으면 여기 적는다.
   **가진 것을 안 쓰는 것도 실점이다.**

---

## 2. 세션 리포트 — `interview/YYYY-MM-DD-N.md`

`N`은 그날의 회차. **문답 5회 이하로 끝난 세션은 만들지 않는다.**
짧은 세션까지 파일을 쌓으면 다음 세션이 읽을 것만 늘어난다.

```markdown
# 모의면접 YYYY-MM-DD-N

- 모드: screen | deep | mixed | full | audit | <주제>
- 다룬 항목: <항목 A>, <항목 B>
- 문답: N회

## 문답

### [항목] <이력서의 어느 문장에서 출발했는지>

**Q1 (L2)** <질문 그대로>
**A** <답변 요지 3~5줄. 원문 속기가 아니라 골자로.>
**판정** L2 통과 / <무엇을 정확히 짚었는지>

**Q2 (L4)** <질문 그대로>
**A** ...
**판정** L4 막힘 / <무엇을 말하지 못했는지. 개념 부족인지 기억의 격차인지 구분해서.>

## 평가

| 축 | 판정 | 근거 |
|---|---|---|
| 구체성 | 양호 | <어떤 수치·고유명이 나왔는지> |
| 인과 | 보통 | <무엇은 서고 무엇은 약한지> |
| 대안 인식 | | |
| 경계 인식 | | |
| 정직성 | | |
| 기여 경계 | | |
| 전이 | | |

## 굳은 답변 (실전에서 그대로 쓸 것)

- **<항목>**: "<답변의 골자를 지원자가 실제로 한 말로>" (약 N초)

## 안 꺼낸 카드

- <진입점 B 중 이번에 얹을 수 있었는데 안 나온 것> → 얹을 자리: <어느 질문>

## 다음 과제

- [ ] <구체적으로. 어느 문서를 읽을지, 무엇을 다시 정리할지까지.>
```

**문답은 요지로 적는다.** 다음 세션이 읽고 이어갈 수 있을 만큼이면 충분하다.

**「굳은 답변」은 지원자가 실제로 한 말로 적어라.** 내가 다듬은 문장을 적으면
실전에서 안 나온다. 지원자의 어휘로 남겨야 입에 붙는다.

---

## 3. INDEX — `interview/INDEX.md`

**이게 다음 세션의 입력이다.** 스킬은 다음 세션에서 이 파일만 읽고도 어디서
시작할지 정할 수 있어야 한다. 개별 리포트는 필요할 때만 펼쳐 본다.

```markdown
# 모의면접 누적 기록 — INDEX

상태값: `미시도` · `L<n> 막힘` · `통과`(5층까지 답함) · `굳음`(2회 이상 통과, 답변 확정)

> **제출본 구분.** 면접관이 읽은 것은 <제출본 파일명>뿐이다.
> **[미제출]** 표시가 붙은 항목은 면접관이 묻지 않는다 — 지원자가 먼저 꺼내야만
> 나오는 카드이므로, 연습 목표가 "답하기"가 아니라 **"끼워 넣기"** 다.

## 세션 이력

| 회차 | 날짜 | 모드 | 항목 | 리포트 |
|---|---|---|---|---|

## 항목 상태

### <카테고리>

| 항목 | 상태 | 마지막 세션 | 비고 |
|---|---|---|---|

## 약점 추이

반복해서 막히는 층과 축. **같은 층에서 3회 막히면 드릴을 반복하지 말고
해당 이론 문서나 원본 자료로 돌아가라고 적는다.**

## 미해결 과제

각 리포트의 「다음 과제」를 모은 것. 해결되면 지운다. 다음 세션은 여기부터 다룬다.

## 굳은 답변

2회 이상 통과해 실전에서 그대로 쓸 수 있게 된 서사. 항목 · 길이 · 리포트 경로 ·
답변 골자.

## 다루지 않은 항목

진입점 중 아직 `미시도`인 것. **세션 편식을 막는다.** 매 세션 여기서 최소 하나.
```

### 상태 전이 규칙

| 상태 | 조건 |
|---|---|
| `미시도` → `L<n> 막힘` | n층에서 답이 무너짐 |
| `L<n> 막힘` → `통과` | 재도전에서 5층까지 답함 |
| `통과` → `굳음` | 2회 이상 통과. 실전 답변이 확정됨 |
| `통과` → `L<n> 막힘` | 재확인에서 다시 무너짐. 강등을 주저하지 마라 |

`굳음`은 아껴서 줘라. 한 번 잘 답한 것은 운일 수 있다.

---

## 4. 보편화 규칙

리포트는 파일로 남고 커밋될 수 있다. 답변에 회사 내부 정보가 나왔더라도
기록할 때는 옮기지 않는다.

**남기는 것** — 활동의 규모와 기간, 기술 스택, 작업의 성격과 방법론,
개선의 상대적 크기, 이미 제출한 문서에 나간 수치.

**빼는 것** — 내부 식별자(티켓 번호·이슈 키·문서 ID), 사내 문서 제목,
보안 태세의 구체적 상세, 프로덕션 장애의 고객 영향과 고객 수,
회사 재무·비용 절대액, 파트너사명, 팀 목표 문서의 내용,
동료 개인에 대한 서술.

면접에서 실제로 할 발화도 어차피 그 선을 넘으면 안 된다. 그래서 이 제약은
연습의 일부다 — **지원자가 그 선을 넘는 발화를 하면 총평에 적어라.**
